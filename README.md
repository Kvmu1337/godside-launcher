## 🛠️ Installation & Setup

1.  **Download:** Grab the latest release from the [Releases](https://github.com/Kvmu1337/godside-launcher/releases) page.
2.  **Extract:** Unzip the downloaded file to a convenient location on your PC.
3.  **Run:** Execute `godside.exe`.
4.  **Login:** Enter your account credentials.
5.  **Launch:** Once logged in, click the "Launch Cheat" button (or similar) while GTA V is running or at the main menu.

*Note: Ensure your Antivirus doesn't interfere with the launcher. You might need to add an exception.*
